This repository contains the data, code, notebook, figures, outputs, and poster associated with the LIS 5963 final project, *Rsearch Trends in Early Childhood Education and Disability: A Text Mining Analysis*. The project uses topic modeling, network analysis, and machine learning classification to analyze patterns in scholarly abstracts collected from Lens.org. It is organized as follows:

* The data/ folder contains the original dataset and the cleaned abstracts dataset.
* The outputs/ folder contains the machine learning prediction CSV files and classification report CSV files for Naive Bayes, SVM, and Logistic Regression models.
* The figures/ folder contains the generated visualizations used in the analysis, including the confusion matrix, topic modeling visualizations, and network analysis graph.
* The poster/ folder contains the final project poster in PDF format.
* The final_project_holland_min.ipynb file contains the annotated Google Colab notebook used for preprocessing, topic modeling, network analysis, and machine learning classification.
